COMO TESTAR NO ANDROID
1. Publique o index.html no GitHub Pages.
2. Abra a página pelo endereço HTTPS do GitHub Pages.
3. Quando aparecer a solicitação do microfone, escolha Permitir.
4. Toque em “Falar agora” e repita a frase em inglês.
5. O sistema mostra uma pontuação e só libera a tarefa quando chegar a 85% ou mais.

IMPORTANTE
Nesta versão HTML, a pontuação de fala é uma estimativa baseada no texto reconhecido pelo navegador (palavras/frase). Não é uma análise fonética real de cada som. Para a versão APK profissional, podemos substituir isso por um motor específico de avaliação de pronúncia.
